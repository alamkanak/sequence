# Manrope

Unmodified variable TrueType font from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/manrope

Source: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf

Copyright 2018 The Manrope Project Authors. Distributed under the SIL Open Font
License 1.1 in OFL.txt. The font bytes are embedded in manrope.js so the independent
studio works without network access, including when opened through file://.
Exports use the real font through Canvas; wordmarks and social cards are PNGs.
